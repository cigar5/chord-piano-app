# 接続スパイク — 10 分手順（実機 2 回目・v0.4）

目的：ATX4 → Bluetooth MIDI → iPhone の MIDIWeb Browser → この Web ページ、の経路が実用になるかを測る。
結果は画面の「JSON を作ってコピー」で出る文字列を、そのまま会話に貼ってください（識別子は含まれません）。

## 準備

1. ATX4 の電源を入れる（取説 p.13：常に Bluetooth 接続の待機状態。ATX4 側の操作は不要）
2. PianoRemote を使っていたら完全に閉じる（アプリ切替画面で上にスワイプ）
3. MIDIWeb Browser で次の URL を開く（開いていたら再読込）：`https://cigar5.github.io/chord-piano-app/src/spike/`
4. 見出しの横の版が **spike-0.4** になっているか見る。前の版の記録は自動で別に保存され、新しく始まります
5. 画面の一番下の「擬似入力を使う」は**オフのまま**にする

## 手順（画面の番号どおり）

| # | やること | 目安 |
|---|---|---|
| ① | 「環境」の Web MIDI＝あり、MIDIWeb API＝あり を見る。機種と iOS 版を入れる（任意） | 30 秒 |
| ② | **「1. Bluetooth で ATX4 を繋ぐ」** → iOS の画面で ATX4 が「接続済み」になったら閉じる → **「2. MIDI を許可」**。状態が **「接続（ATX4 Bluetooth…）」** になれば成功。鍵盤を 1 つ弾いて「受信あり ✓」になるか見る。ならなければ 2 をもう一度 | 2 分 |
| ③ | 鍵盤ガイドの **「③ 単音を始める」** → **青く光る鍵盤**を弾く。合っていれば緑になり、**指を離すと次へ**。違う鍵盤は橙（やり直し）。弾いても何も変わらないときは「押しても反応しない → 次へ」。正しく 100 回 | 3〜4 分 |
| ④ | **「④ 三和音を始める」** → 青く光る **3 つを同時に**押す。合っていれば緑になり、**指を全部離すと次へ**（12 個。弾けなければ「この和音を飛ばす」） | 2 分 |
| ⑤ | ダンパーペダル（右）を 5 回、深く踏んで離す | 20 秒 |
| ⑥ | ⑥ の **「記録してから再読込」** → ホームに戻って別アプリを開く → MIDIWeb Browser に戻る。状態が「接続」に戻るか見る。赤い案内が出たら、その通りに「2. MIDI を許可」 | 1 分 |
| ⑦ | **「電源を切った」**を押して ATX4 の電源を切る → 電源を入れて **「電源を入れた」**を押す → ⑦ の右の灰色の表示が **「届いた（入れてから ○ 秒）」** になるまで鍵盤を 1 つずつ弾く（電源を入れ直すと自動では繋がらない。**「1. Bluetooth で ATX4 を繋ぐ」**を押す）。JSON は「届いた」の後で | 1〜2 分 |
| ⑧ | 遅延感（0〜4）と負担感（1〜5）を選ぶ | 10 秒 |
| ⑨ | **「JSON を作ってコピー」** →「コピーしました」と出たら会話に貼る（出なければ、下の枠を長押し →「すべてを選択」→「コピー」） | 30 秒 |

途中で「変だ」と思ったら、その場で「いま変だった（マーカー）」を押してください。

選んでいるほう（③ か ④）のボタンだけが青くなり、問題の上に「いま：③ 単音」のように出ます。途中で切り替えても、戻ると続きからです。実施中のボタンは、3 秒以内に 2 回押したときだけ最初からやり直しになります。

## 鍵盤ガイドの見方

- ドレミとアルファベット：ド=C、レ=D、ミ=E、ファ=F、ソ=G、ラ=A、シ=B
- 上の小さい絵がピアノ全体（88 鍵）。青い枠の部分を、下に大きく描いています
- ドは「黒鍵 2 本のかたまり」のすぐ左の白鍵。ファは「黒鍵 3 本のかたまり」のすぐ左（ドとファは取り違えやすい）
- 押した鍵盤が大きい絵の外にあるときは、全体図に点で出て、大きい絵のすぐ下に「◀ 範囲外（左）：ファ（F3）…」のように名前が出ます。④ では「押しているのは…／弾くのは…」も出ます
- 大きい絵の左端が「真ん中のド（C4）」。88 鍵のピアノでは、鍵盤のほぼ真ん中（少し左寄り）
- ③④ は、同じ名前の鍵盤ならどの高さで弾いても正解

## 繋がらないとき（順に試す）

1. 「2. MIDI を許可」をもう一度押す（ポートの取り直し）
2. ATX4 の電源を入れ直してから、「1」→「2」
3. GarageBand の「設定 > 詳細 > Bluetooth MIDI デバイス」で ATX4 を接続してから、MIDIWeb Browser に戻って「2」
4. それでも駄目なら止めて、画面の「接続」欄の表示をそのまま教えてください

## 仮合格値（利用者の環境で校正する前の暫定値・要確認）

初回接続 120 秒以内／再読込後の復帰 30 秒以内／電源再投入後 60 秒以内／再現する欠落・重複・孤立 note-off・stuck・切断がゼロ／受信後描画 p95 50 ms 以下／遅延感 1 以下。

## この診断で分かること・分からないこと

- 分かる：Web MIDI API と MIDIWeb の API の有無、権限、ポートと製造元の表記、届いたイベントの種類と時刻、受信から画面描画の直前までの遅れ、再読込・電源再投入からの復帰と、そのとき ATX4 を何で見つけたか（通知・1 秒ごとの取り直し・押し直し・自動）、ATX4 が note-off を「velocity 0 の note-on」で送るか、三和音の 3 音の立ち上がりのずれ
- 分からない：鍵盤を押してから iPhone に届くまでの遅れと欠落（ページは「届いた後」しか見えない）。届かなかった音は「押しても反応しない」ボタンとマーカーで記録します
